# dsh-agent-md

**给 DeepSeek Harness（DSH）用的项目级记忆插件。**

长对话和长任务里，模型能读的上下文有限，早先的约束、决定和任务要求会被挤出窗口，或者淹没在后面的噪声里，于是出现"失忆"：写代码时忘了需求，做完一件事忘了另一件。

这个插件把重要内容落到**当前工作目录**的 `agent.md`，并在**每一次模型请求**里自动注入。模型不需要"记得去读文件"——它每次请求都在眼前。

## 它怎么工作

1. **写**：模型判断出重要的事实、约束、任务要求时，调用 `agentmd_write` 记进 `agent.md`，条目带短 id 和权重（1–3）。
2. **注入**：每次模型请求，插件现场读取 `agent.md`，渲染成摘要塞进系统提示（进行中任务、事实约束；已完成条目折叠成一行统计）。
3. **修剪**：任务做完，`agentmd_update` 标记 `done` 并把权重降到 1；彻底过时再 `agentmd_forget`。记忆始终是几百字级，不会反过来拖慢模型。

注入内容有字符上限（默认 4000），文件再长也不会把上下文吃满。

## 安装

要求：DSH（桌面版或 Web 版）、Node.js ≥ 22。

1. 拿到本仓库目录（clone 或下载）。
2. 在 DSH 里让它安装这个目录：把目录的绝对路径告诉 agent，用插件管理器的"安装 bundle"指向该目录即可。
3. 安装完成后插件即生效；如果提示需要重启，就重启一次 DSH。

安装后模型工具列表里会出现 `agentmd_write / agentmd_update / agentmd_forget / agentmd_read`，系统提示里会多出一节"项目记忆 agent.md"。

## 使用

你什么都不用做。需要时也可以直接说：

- "把这条记到 agent.md" —— 模型写一条；
- "这件事已经做完了，降权" —— 模型标记完成并把权重降到 1；
- "agent.md 里那条过时的删了" —— 模型删除。

也可以自己打开 `agent.md` 编辑。插件生成的文件长这样：

```md
# agent.md · 项目记忆

<!-- dsh-agent-md:managed v1 -->

## 事实与约束

- Python 3.12，禁止新增三方依赖 <!--m:1a2b w3-->

## 任务

- [ ] 把评测集扩到 30 条 <!--m:3c4d w3-->
- [x] 写 README <!--m:5e6f w1-->
```

`<!--m:id wN-->` 是条目元数据（id + 权重），手工改内容时可以保留或删掉；不带元数据的行会原样保留在 `## 手写笔记` 段，插件改写文件时不会吃掉它们。

## 配置

在 DSH 的 profile 配置里，给插件行 `agent-md` 的 `config` 加字段：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `memoryFile` | `agent.md` | 相对工作目录的文件名；绝对路径会被忽略 |
| `maxPromptChars` | `4000` | 每次注入的字符上限，超出截断并提示用 `agentmd_read` |

## 卸载

在 DSH 里移除插件（插件管理器"移除 bundle"），或停用它。已生成的 `agent.md` 不会被删除，需要的话自己删。

```bash
npm run check   # 语法检查
npm test        # 21 项冒烟测试，用假 ctx 跑，不需要运行 DSH
```

目录：

```

```

## 注意

- `agent.md` 是**本机对话记忆**，通常不要提交到 git。建议在项目里把它加进 `.gitignore`，或者接受它在版本库里的噪声。
- 记忆按**工作目录**隔离：换项目目录就换记忆，不会串。
- 插件不会主动记录密钥、口令或隐私内容（提示词里明确要求模型不记）。
